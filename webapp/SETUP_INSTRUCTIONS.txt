========================================================
  SALES REPORTS WEB APP — COMPLETE SETUP INSTRUCTIONS
========================================================


PART 1: UPDATE THE EXISTING APP REGISTRATION (3 small changes)
--------------------------------------------------------------

Go to portal.azure.com > Microsoft Entra ID > App registrations
Search for the app by Client ID: a59502c1-0954-402b-92cb-e644ac9f0af5


STEP 1 — Add Redirect URIs

1. Click "Authentication" in the left sidebar
2. Under "Platform configurations", if you don't see a "Web" section,
   click "+ Add a platform" > "Web"
3. Add these two redirect URIs:

   http://localhost:5000/auth/callback
   https://achim-sales-reports.azurewebsites.net/auth/callback

4. Click Save


STEP 2 — Enable ID Tokens

1. Still on the Authentication page, scroll down to
   "Implicit grant and hybrid flows"
2. Check "ID tokens"
3. Leave "Access tokens" unchecked
4. Click Save


STEP 3 — Add User.Read Permission

1. Click "API permissions" in the left sidebar
2. Check if "Microsoft Graph > User.Read (Delegated)" already
   appears in the list
3. If it's NOT there:
   - Click "+ Add a permission"
   - Select "Microsoft Graph"
   - Select "Delegated permissions"
   - Search for "User.Read", check it
   - Click "Add permissions"
4. If you see a banner "Grant admin consent for Achim Importing",
   click it and confirm

Done. No new secrets, no new IDs needed.

PART 2: CREATE THE AZURE APP SERVICE (Free Tier)
-------------------------------------------------

STEP 1 — Create the Web App

1. Go to portal.azure.com
2. Search for "App Services" in the top search bar
3. Click "+ Create" > "Web App"
4. Fill in:

   Subscription:       Your Azure subscription
   Resource group:     Click "Create new", name it "rg-sales-reports"
   Name:               achim-sales-reports
   Publish:            Code
   Runtime stack:      Python 3.12
   Operating System:   Linux
   Region:             East US
   Pricing plan:       Click "Create new" > select F1 (Free)

5. Click "Review + create" > "Create"
6. Wait for deployment to complete (1-2 minutes)


STEP 2 — Set Environment Variables

1. Go to your new App Service > "Configuration" (under Settings)
2. Click the "Application settings" tab
3. Click "+ New application setting" and add each of these:

   Name:                          Value:
   ----------------------------   -----------------------------------------
   GRAPH_TENANT_ID                17d20374-b62d-404e-9a3a-6aa177aa98a4
   GRAPH_CLIENT_ID                a59502c1-0954-402b-92cb-e644ac9f0af5
   GRAPH_CLIENT_SECRET            (the secret from your .env file)
   D365_ENV_URL                   https://achim-prod.operations.dynamics.com/
   FLASK_SECRET_KEY               (see below how to generate)
   SCM_DO_BUILD_DURING_DEPLOYMENT true

   To generate the Flask secret key, open PowerShell and run:
   python -c "import secrets; print(secrets.token_hex(32))"
   Copy the output and paste it as the value.

4. Click "Save" at the top
5. Click "Continue" when it warns about restarting


STEP 3 — Set the Startup Command

1. Still in Configuration, click the "General settings" tab
2. In the "Startup Command" field, enter:

   gunicorn --bind=0.0.0.0:8000 --timeout 120 --chdir /home/site/wwwroot webapp.app:app

3. Click "Save"


STEP 4 — Install Azure CLI

1. Download from https://aka.ms/installazurecli
2. Run the installer
3. Close and reopen PowerShell after installing


STEP 5 — Deploy Your Code

1. Open PowerShell

2. Log in to Azure:
   az login
   (A browser window will open — sign in with your Azure account)

3. Navigate to the scripts folder:
   cd "C:\Users\Menny\OneDrive - Achim Importing Co., Inc\Achim Importing Co., Inc. Team Site - D365 F&O\scripts"

4. Deploy:
   az webapp up --name achim-sales-reports --resource-group rg-sales-reports --runtime "PYTHON:3.12" --sku F1

   This zips your code and uploads it. Takes 1-2 minutes.


STEP 6 — Verify It Works

1. Open a browser and go to:
   https://achim-sales-reports.azurewebsites.net
2. You should see the Microsoft login page
3. Sign in with an email from user_map.json (e.g. mennyg@achimonline.com)

PART 3: SET UP YOUR SUBDOMAIN REDIRECT (Dreamhost)
----------------------------------------------------

This makes sales.yourdomain.com forward to your Azure app.
Free, no Azure upgrade needed.

1. Log in to panel.dreamhost.com
2. Go to Domains > Manage Domains
3. Click "Add Hosting to a Domain / Sub-Domain"
4. Select "Redirect"
5. Fill in:
   - Domain to redirect:  sales.yourdomain.com
   - Redirect to URL:     https://achim-sales-reports.azurewebsites.net
6. Save

Your salesmen can bookmark sales.yourdomain.com and it takes them
straight to the app. The browser URL will change to the Azure URL
after the redirect.
